# The Guitar Registry - Landing Page

The Guitar Registry is a blockchain-based platform that creates the world's first permanent, cross-brand database for electric guitars, preserving the complete history and provenance of every legendary instrument. Targeting the $8 billion vintage guitar market, the platform uses cryptographically-signed attestations from experts, owners, and witnesses to create unalterable records that enhance authenticity and value while preserving cultural heritage. The project addresses the critical problem of vanishing guitar history by replacing scattered, unreliable documentation with a permanent, decentralized registry that survives forever—no matter what happens to companies, websites, or platforms.

## Project Structure

- `index.html` - Main landing page
- `landing.css` - Styles and responsive design
- `llms.txt` - LLM-friendly content summary
- `favicon.ico` - Site icon
- `ignore-images/` - Design assets and mockups

## Maintaining llms.txt

The `llms.txt` file provides an LLM-friendly summary of the landing page content for AI systems and search engines. To keep it synchronized with the main content:

### Update Process
1. **When making changes to `index.html`**: Update the corresponding sections in `llms.txt`
2. **Update the timestamp**: Change the "Last updated" date in `llms.txt` to match your changes
3. **Verify synchronization**: Use the last commit timestamp to ensure both files are in sync

### Content Structure
The `llms.txt` file mirrors the HTML structure with these sections:
- Overview and Mission
- Problem Statement (3 key issues)
- Solution Description
- Key Features (6 main features)
- Vision Statement
- Call to Action
- Additional context (target audience, technology, market data)

### Verification
- Check that all headings, taglines, and key content from `index.html` are represented
- Ensure the "Last updated" timestamp reflects recent changes
- Compare commit timestamps between `index.html` and `llms.txt` to verify synchronization

The timestamp in `llms.txt` provides explicit verification for LLMs and other systems that the content is current and synchronized with the main landing page.
